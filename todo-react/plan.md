# 📝 Todo 앱 React 마이그레이션 기능 명세서

## [도메인 1] 주간 캘린더
### 책임: 현재 선택된 날짜 관리 및 주간 달력 연산/UI
- [ ] 현재 선택된 날짜 기준 월~일 배열 생성 로직 (getWeekDates)
- [ ] 요일, 날짜 숫자 가로 나열 UI 컴포넌트화
- [ ] 날짜 클릭 시 상위 상태(selectedDate) 업데이트
- [ ] 이번 주 날짜 목록 표시
  - 1) 각 날짜 카드 하단에 해당 날짜의 Todo 개수(count) 표시
- [ ] 이전 주차 / 다음 주차 이동 UI 버튼 및 주 단위 이동 로직 (+-7일)
- [ ] 날짜 선택 상태에 따른 3가지 시각적 구분 스타일 적용 (CSS/조건부 렌더링)
  - 1) [오늘 날짜]이면서 선택되지 않은 경우: 오늘임을 알리는 독자적인 하이라이트 색상
  - 2) [선택된 날짜]인 경우: 현재 내가 보고 있는 날짜임을 알리는 강조 색상
  - 3) [선택되지 않은 다른 날짜들]: 기본 무채색 스타일

## [도메인 2] Todo 관리
### 책임: todos 데이터의 CRUD 처리, 로컬스토리지 연동, 필터링된 목록 노출
- [ ] **[Create] 새로운 Todo 생성 구역**
  - [ ] 할 일 텍스트 입력창 및 추가 버튼 UI 구현
  - [ ] 빈 값 입력 후 추가 시도 시 에러 메시지 노출 (2.5초 후 자동 히든)
  - [ ] 입력창에서 Enter 키 입력 시 Todo 추가 기능 트리거
  - [ ] Todo 생성시 현재 캘린더에서 [선택된 날짜]가 Todo의 date 속성으로 자동 저장

- [ ] **[Read / Update / Delete] Todo 목록 및 아이템 구역**
  - [ ] 생성된 Todo 목록 리스트 UI 구현
  - [ ] 개별 Todo 아이템 내 완료 / 수정 / 삭제 버튼 UI 구현
  - [ ] 완료 토글 처리 시: 해당 Todo 데이터 상태 변경 및 텍스트 취소선 스타일 적용
  - [ ] 삭제 처리 시: 목록에서 부드럽게 사라지는 애니메이션 적용 및 데이터 삭제
  - [ ] 수정 모드 진입 시: 텍스트가 인풋창으로 전환되며, 수정 후 저장/취소 기능 제공
  - [ ] 수정 중 빈 값 상태로 저장 시도 시 에러 메시지 노출 (2.5초 후 자동 히든)

- [ ] **[Filter] 필터링 및 데이터 연동 구역**
  - [ ] 전체 / 진행 중 / 완료 필터 목록 노출
  - 1) 현재 선택된 필터 탭에 하이라이트 스타일 적용
  - 2) 필터 탭 클릭 시 상위 필터 상태(currentFilter) 업데이트
  - 3) 선택된 필터 조건 및 선택된 날짜에 맞는 Todo 항목만 필터링하여 화면에 노출
  - 4) 새로운 Todo를 추가해도 현재 선택되어 있는 필터 탭 상태가 유지됨
  - 5) 현재 날짜/필터 조건에 해당하는 Todo가 하나도 없을 시 안내 문구 노출 (ex. "이 날의 할 일이 없어요.", "진행 중인 할 일이 없습니다.")

- [ ] **[Data Layer] 데이터 동기화**
  - [ ] 최초 앱 로드 시 로컬스토리지에서 기존 todos 배열 안전하게 복원
  - [ ] Todo의 추가, 수정, 삭제, 완료 상태 변경 등 데이터가 변할 때마다 로컬스토리지 실시간 동기화(저장)
